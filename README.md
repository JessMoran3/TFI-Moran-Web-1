Trabajo Final Integrador – Programación Web 1



\*\*Descripción del proyecto\*\*



Mi pelu online es un sitio web informativo para una peluquería, desarrollado como Trabajo Final Integrador de la asignatura Programación Web 1.



El sitio busca ofrecer un espacio donde cada persona pueda conocer los servicios disponibles, explorar diferentes estilos y realizar consultas. Su propuesta se basa en la libertad de expresión, la diversidad y la identidad personal.



\*\*Estudiante:\*\* Jessica Moran

\*\*Asignatura:\*\* Programación Web 1

\*\*Carrera:\*\* Tecnicatura Universitaria en Desarrollo de Software

\*\*Institución:\*\* Universidad de La Punta



\### Tecnologías utilizadas



\- HTML5

\- CSS3

\- JavaScript



\### Estructura del sitio



\- \*\*Inicio:\*\* presentación del sitio y carrusel de imágenes.

\- \*\*Servicios:\*\* descripción de los servicios ofrecidos, tabla de precios y promociones.

\- \*\*Contacto:\*\* formulario de consultas con validaciones realizadas mediante JavaScript.



\### Funcionalidades



\- Navegación entre las distintas páginas.

\- Carrusel de imágenes interactivo.

\- Diseño adaptable a dispositivos móviles.

\- Formulario de contacto con validaciones de datos.

\- Visualización de un resumen de los datos ingresados.
